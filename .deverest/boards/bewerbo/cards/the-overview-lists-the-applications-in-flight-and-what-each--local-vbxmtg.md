The overview holds no list of applications. The concept shows each one with its employer, its reference number and its state — draft, sent, invitation, waiting — and above them the two or three things still outstanding. Without it a user applying to several employers cannot see where anything stands or return to an unfinished application.

**Acceptance criteria**
- Every application the user has started is listed with its employer and its current state.
- The outstanding steps are named and lead to the place where each is done.
- Selecting an application opens it where the user left it.
