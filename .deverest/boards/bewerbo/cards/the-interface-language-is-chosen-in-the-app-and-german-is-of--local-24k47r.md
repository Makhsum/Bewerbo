The interface language follows the phone's locale and falls back to English, and there are no German resources at all. A phone bought in Germany therefore shows English to someone who came here for a German application. Separately, the profile's input-language selector governs only what the user types, which invites the two to be confused.

**Acceptance criteria**
- The user picks the interface language inside the app, independently of the phone.
- German is among the languages offered.
- The interface language and the input language are named so they cannot be mistaken for one another.
