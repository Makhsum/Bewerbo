The app is navigated through five tabs — overview, profile, posting, application and Mappe — but the steps are sequential: a match cannot be made before a posting has been pasted, and the match already appears inside the posting tab rather than as a place of its own. Tabs promise a freedom of order the product does not have, and the user has to know the sequence in advance to use it.

**Acceptance criteria**
- Producing an application is one path the user moves along, not a set of tabs whose order must be known.
- Places a user returns to stay reachable at any time; steps of the flow do not pose as places.
