On first launch the overview shows "0 applications", a readiness ring reading 0 of 100, three empty meters and a data-protection notice. It offers no action at all — the only things that can be tapped are the five navigation tabs, so the user has to guess where to begin. The score is an invented measure and says nothing on an empty profile.

**Acceptance criteria**
- A new user is offered one clear first step from the overview.
- The overview shows what is outstanding rather than a score out of 100.
