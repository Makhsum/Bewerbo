The Lebenslauf template is chosen on the profile screen, below the button that produces the document. It is a decision about the document, taken in the wrong place and after the action it belongs to, and a user still filling in a profile has no grounds yet to choose between Klassisch, Modern and Fachlich.

**Acceptance criteria**
- The template is chosen where the document is shown.
- The profile screen ends with the action that leads out of it.
