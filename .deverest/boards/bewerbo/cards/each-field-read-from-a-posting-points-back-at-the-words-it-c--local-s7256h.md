The posting screen promises that every field below links back to the words it came from. The source text does highlight the passages, but nothing ties a highlight to the field it produced, so the promise is not kept and the user cannot check whether the reading is right. In the concept each passage and its field carried the same number.

**Acceptance criteria**
- A field read from the posting and the passage it came from are visibly tied to each other.
- Selecting either one shows the other.
- A field the app could not find is distinguishable from one it read wrongly.
