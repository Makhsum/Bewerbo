The interface speaks three languages at once: "Создать Anschreiben", "Попадёт в Betreffzeile", "Zeitstrahl 2026 – 2026", "VORLAGE", "TON DES ANSCHREIBENS", "MASCHINENLESBARKEIT", a tab named Mappe. Russian and Ukrainian resources exist but only half the strings use them. Finishing the translation is not enough on its own: some German words are worth keeping, because the user meets them in real postings, and nothing currently says which.

**Acceptance criteria**
- German is kept only for the terms a user meets in job adverts, and each is explained once where it first appears.
- Every other label stands in the user's language.
- No screen mixes languages inside one sentence or one control.
