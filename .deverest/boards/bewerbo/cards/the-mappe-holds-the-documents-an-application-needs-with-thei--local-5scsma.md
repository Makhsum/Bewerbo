A German application travels with its certificates: Arbeitszeugnisse, language certificates, the assessment of a foreign degree. The concept shows each with whether it is on file or still missing, and marks the ones a posting demands. The app has the tab but nothing behind it.

**Acceptance criteria**
- A user can file a document and see that it is on file.
- A document a posting demands and the user does not have is shown as outstanding.
- Filed documents are offered as enclosures when an application is exported.
