Only the first page of the application is shown, and the file can only be saved. The concept shows every page of the bundle as a thumbnail to move between, lets the user choose which parts go into the file, and offers to send it by e-mail — which is how most German applications actually arrive.

**Acceptance criteria**
- Every page of the application can be reached from the preview.
- The user chooses which parts the exported file contains.
- The finished file can be sent by e-mail from the app.
