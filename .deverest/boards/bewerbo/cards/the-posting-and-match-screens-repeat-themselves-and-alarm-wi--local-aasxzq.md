Each field read from a posting takes a large card with its own correction link, so five fields fill two screens and five identical links do one job. A missing start date is marked in red although most adverts name none, and a correctly read reference number asks to be checked. On the match screen the same sentence about a requirement not being claimed is printed under every one of the five entries.

**Acceptance criteria**
- The fields read from a posting fit on one screen and are corrected through a single affordance.
- A marker draws attention only where the user has to act.
- What holds for a whole group of requirements is said once.
